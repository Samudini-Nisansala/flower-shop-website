# 🌸 Flower Shop Website

A modern and responsive e-commerce website for a flower shop built with PHP & MySQL.

This project was developed as part of my HNDIT studies to manage online flower orders easily.

### 🔗 Live Demo & GitHub
- *GitHub Repository:* https://github.com/Samudini-Nisansala/flower-shop-website
- *Developer:* Samudini Nisansala

### ✨ Features
- 🏠 Beautiful Homepage with product listing
- 🛒 Add to Cart & Remove from Cart
- 🔐 User Registration & Login System
- 📦 Checkout & Order Management (My Orders)
- 👩‍💼 Admin Panel - Manage Products & Messages
- 📩 Contact Us Page
- 📱 Fully Responsive Design

### 🛠️ Tech Stack
- *Frontend:* HTML5, CSS3, JavaScript
- *Backend:* PHP
- *Database:* MySQL (XAMPP)
- *Server:* Apache

### ⚙️ How to Run This Project
1. Install XAMPP
2. Clone or download this repository to htdocs folder:
   C:\xampp\htdocs\flower
3. Start Apache & MySQL in XAMPP
4. Import the database:
   - Go to http://localhost/phpmyadmin
   - Create a database named flower_db
   - Import the .sql file
5. Run the project:
   http://localhost/flower/index.php

### 📂 Project Structure
- index.php - Home Page
- admin.php / admin_products.php - Admin Panel
- db_connect.php - Database Connection
- image/ - All flower images
